# Sustitucion-de-Liskov
El proyecto ilustra el principio de sustitución de Liskov al permitir que las clases Fisico y Digital proporcionen distintas formas de calcular descuentos sin romper el comportamiento general establecido por Producto.
La aplicación de este principio favorece la reutilización, el polimorfismo y la confiabilidad del código. Como mejora, utilizar una función que reciba una referencia a Producto permitiría demostrar de manera más evidente que ambas clases derivadas pueden sustituir a la clase base sin alterar el funcionamiento esperado del programa.
